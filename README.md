# Best Business Language (BBL)
![drizzled_the_thicc_raindrop.png](drizzled_the_thicc_raindrop.png)

The Best Business Language. Better than SAP ABAP, better than PeopleCode. It's 100000x more gooder.

BBL is a strongly, statically typed, data-centric language where structure and stability are king, while relying on the ease of readability from the syntax of Go. 

BBL features native support for local tables like ABAP, but retains common well-known data structures like Arrays, Dictionaries, Tuples, and lists. 

BBL also features rich pattern matching, and SQL/LINQ like table accessibility.
